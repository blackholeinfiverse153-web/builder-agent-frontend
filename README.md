# BHIV Builder Agent Frontend

A developer dashboard and workspace for the BHIV Builder Agent platform. Built with React, TypeScript, Vite, Tailwind CSS, Lucide React, and CodeMirror 6.

## Requirements
- Node.js 18+ (tested on Node.js 22)
- npm 9+

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

### 3. Run Development Server
```bash
npm run dev
```
Accessible at: `http://localhost:5173`

### 4. Run Build
```bash
npm run build
```

### 5. Run Unit Tests
```bash
npm test
```
